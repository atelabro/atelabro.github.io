# atelabro.github.io

GitHub Pages user site for AL4Bro. Hosts app-ads.txt, privacy policy, and support pages.

## Live URLs

- https://atelabro.github.io/ (AL4Bro developer profile listing the apps)
- https://atelabro.github.io/support.html (currently DuckOff support)
- https://atelabro.github.io/app-ads.txt (must stay at the root for AdMob)
- https://atelabro.github.io/duckoff/privacy.html
- https://atelabro.github.io/duckoff/support.html
- https://atelabro.github.io/cageri/
- https://atelabro.github.io/miso/privacy.html

## Store URLs in use

- DuckOff App Store privacy policy URL: `https://atelabro.github.io` (root). Apple only allows changing it with a new app version.
- DuckOff Google Play privacy policy URL: `https://atelabro.github.io/alab-game-common/` (separate repo).
